# The narrated example: Neap, "Slack water"

A 21 second narrated film for a made-up tide app. It shows the kit's narration step end to end:
`narration.txt` voiced locally with Kokoro-82M, a picture keyed to the words, captions burned in, a
score ducked under the voice, and the AI-voice credit on the end card. Read `docs/narration.md`
first. Never edit this film: copy what you want into your own.

## How the voice drives it

`narration.txt` is the script. `npm run narrate -- neap` voices it (the beatmap's `NARRATION` sets
the voice, speed and first frame) and writes the timings to `data/narration.json`. `moments.ts`
turns words into frames (`wordAt(words, 'stops')`), and every scene and the score key on those, so
re-voicing the script moves the film with it. The light stops on "stops", the times appear on
"when", the other harbours on "every", the hero time on "14:52", the end card on "Go", and the
music takes the room 0.75 s after the last word.

## Files

| File | What |
|---|---|
| `brief.md`, `treatment.md`, `expected.md` | the paper trail |
| `narration.txt` | the script |
| `beatmap.ts` | frame rate, length, where the voice starts, the end |
| `moments.ts` | every picture moment, from the words |
| `Neap.tsx`, `film.ts`, `theme.ts` | the film |
| `score.mjs` | the bed, from the same words, ducked under the voice with `audio/voice.mjs` |
| `data/narration.json` | generated by `npm run narrate -- neap` |

`public/films/neap/narration/` (the voice, captions and record) and `public/films/neap/score.wav`
ship with the kit, so the film opens and renders without the narration packages installed. Running
`npm run narrate -- neap` needs them (`npm run narrate -- --setup`) and rewrites the voice;
`npm run score -- neap` rebuilds the score.

## What was and was not checked

Rendered, mastered and released on macOS (Apple Silicon): every release gate passed, including the
narration step (the voice 15.5 dB over the bed under speech) and all 16 audit gates. One cold
explain-back (`examples/neap/reviews.md`). Nobody has listened to the voice or the mix: the cadence
check in `docs/narration.md` is still to do.
